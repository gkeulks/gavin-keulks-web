# gavinkeulks.com

Professional site for Gavin Keulks — Astro, deployed to Cloudflare Pages.

## Commands

| Command           | Action                                        |
| :---------------- | :-------------------------------------------- |
| `npm install`     | Install dependencies                          |
| `npm run dev`     | Dev server at `localhost:4321`                |
| `npm run build`   | Build to `./dist/` and index with Pagefind    |
| `npm run preview` | Preview the production build locally          |

## Deployment

Cloudflare Pages builds from `main`. Build command `npm run build`, output `dist/`.

See `AGENTS.md` for project context and conventions.
